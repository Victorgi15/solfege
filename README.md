# Solfège

**Note à note** est un jeu de lecture musicale interactif, en français, qui aide à reconnaître les notes sur une portée et à les retrouver sur un clavier.

## Jouer

Ouvrez [`index.html`](index.html) dans un navigateur récent. Aucune installation ni compilation n’est nécessaire.

## Fonctionnalités

- Plusieurs niveaux de difficulté
- Lecture des notes en clés de sol et de fa
- Exercices de reconnaissance et de placement des notes
- Clavier interactif avec raccourcis AZERTY
- Score, série de bonnes réponses et mode sans fin
- Son activable ou désactivable

## Technologies

Le jeu est réalisé avec HTML, CSS et JavaScript natifs dans un fichier autonome. Les polices DM Sans, DM Mono et Manrope sont chargées depuis Google Fonts.
